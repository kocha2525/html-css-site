CSS セレクタ詳細

セレクタとは？

セレクタとは、「どの要素にCSSを適用するか」 を指定するためのもの。
HTML のどの部分を装飾するかを決める“指名”の役割を持つ。

基本のセレクタ

セレクタ 例 意味
タグセレクタ p {} pタグすべてに適用
classセレクタ .box {} class="box" に適用
idセレクタ #title {} id="title" に適用

要素セレクタ（もっとも基本）

タグ名をそのまま指定してスタイルを当てるセレクタ

    p {
    color: blue;
    }

→ ページ内の <p> 全部が青になる。

クラスセレクタ（最もよく使う）

複数の要素に同じデザインを当てたいときに使うセレクタ

    <p class="lead">文章</p>

    .lead {
    font-size: 20px;
    color: #333;
    }

　このコードだとleadと名前を付けたクラスに含まれる
「フォントサイズ・色を変える」 という意味になる

→ class は何回でも使える。デザインの“グループ名”。

子孫セレクタ（スペース）

「Aの中にあるBだけ」にスタイルを当てるセレクタ

div p {
    color: red;
}

divの中のpだけが赤色に変わる

子セレクタ（>）

「すぐ下の階層の子だけ」を指定するセレクタ

.box > p {
    color: blue;
}

→.box直下のpだけ青色になる

隣接セレクタ（+）

「A のすぐ後ろにある B だけ」を選ぶセレクタ

h2 + p {
    color: red;
}

→h2のすぐ後ろのpが赤くなる

隣接セレクタ　成功例・失敗例

成功例

どちらのコードもh2のすぐ次にpが来ているから色変わる！

失敗例

この場合はh2のすぐ次にpが来ていないため、色変わんない

兄弟セレクタ（~）

「Aより後ろにあるBを全部選ぶ」セレクタ

h2 ~ p {
    color: gray;
}

h2の後ろのpが全部赤になる！

隣接セレクタ・兄弟セレクタ　違い

セレクタ 意味 例えると
A＋B Aのすぐ後ろのB１つだけ 「すぐ隣の席の人」
A～B Aの後ろにあるB全部 「後ろの席にいる人全員」

属性セレクタ

属性セレクタは「特定の属性を持つ要素だけ」を選ぶためのセレクタ

属性がなんやったか忘れた方はクリックしてね♡ 
    セレクタ[属性  ]{
        ここにどうさせたいか書くよ
    }
書き方 意味
a[target] target属性を持つ a全部が対象
かっこの中に属性だけ入力すると
その属性を持つ要素全部に干渉する
input[type="text"] type="text" の inputだけ対象
=""が追加されると""内にある値（文字とか）と
完全一致するものだけに干渉する
a[href^="https"] https で始まるリンクだけ対象
^=""が追加されると前方が""内と一致するものだけに干渉する
a[href$=".pdf"] .pdf で終わるリンクだけ対象
$=""が追加されると後方が""内と一致するものだけに干渉する
a[href*="google"] google を含むリンク全部が対象
*=""が追加されると""内に書かれたものが含まれたところ
全部に干渉する

属性セレクタの利点

  • 無駄にクラスを増やさずに済む
  • 慣れてくるとUIデザインでよく使う
  • JavaScriptと相性がいい

疑似クラス

リンクやボタンの“状態”に応じてスタイルを変える。

    セレクタ :疑似クラス{
        ここにどうさせたいか書くよ
    }
疑似クラス 意味
:link 未訪問のリンク
:visited 訪問済みのリンク
:hover マウスを乗せた時
:active クリックした瞬間
:focus 入力欄が選択された時
:first-child 最初の子要素
:last-child 最後の子要素
:nth-child(2) 2番目の要素
:nth-of-type(2) 同じタグの中で2番目の要素

特にややこしい疑似クラスを抜粋して紹介

先ほどの表の最後の３つは特にミスや勘違いが多いのでかみ砕いて説明するよ

nth-child（順番で指定）

「n番目の要素」にスタイルを当てる。

()内の数字は何番目かの指定だにょ 

    p:nth-child(3) {
    color: red;
    }

→ 3番目の p だけ赤になる。

※三番目がもしpではなかったら適応されない！

↑これは三番目がｐ要素でないからなんも変わらん！

nth-of-type（同じタグの中でn番目）

タグの種類ごとに数える。

    p:nth-of-type(2) {
    font-size: 20px;
    }

→ 2番目の p だけ大きくなる。

※pのタグしか見ないから間にliとかあっても飛ばして三番目のpに適応される

↑これは間のｐでないものを飛ばして上から数えるからcssが反映される！

疑似クラスで守ってほしいお約束

複数の違う疑似クラスを使うとき、
実は順番を気にしないとうまく動かないかも…

順番（強さ） 疑似クラス
1番目 :link
2番目 :visited
3番目 :hover
4番目 :active

なんで順番が大事なんか

　　　　　↓　　　　　

cssは後に書いたものが優先される仕様があるから！

こんな風に書いてしまうと先にvisitedのほうが効くから
hoverが効かなくなってしまう

※それ以外の疑似クラスはそこまで順番が大事なわけではないので
あまり順番を気にしなくてもよい

セレクタの優先順位

複数のcssがかぶったとき、どれが先に優先されるか

強さ 例
① !important color:red !important;
② インラインCSS <p style="color:red">
③ idセレクタ #title
④ classセレクタ .box
⑤ タグセレクタ p

よくある間違い

  • class と id の使い分けが逆になっている
  • 子孫セレクタのスペースを忘れる（divp ではなく div p）
  • hover が効かない → a:link や a:visited の順番が逆
  • nth-child と nth-of-type の違いが分からない
