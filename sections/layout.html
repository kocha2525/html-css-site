レイアウト応用

レイアウトとは？

Webページの「配置」を決める技術。 HTML で骨組みを作り、CSS でレイアウトを整える。

レイアウトの主な手法

  • float
  • flex
  • position
  • grid

2カラム（float版）

.left {
    float: left;
    width: 70%;
}
.right {
    float: right;
    width: 30%;
}

2カラム（flex版）

.container {
    display: flex;
}
.left {
    flex: 3;
}
.right {
    flex: 1;
}

position の種類

値 説明
relative 元の位置からずらす
absolute 親基準で配置
fixed 画面に固定
sticky スクロールで固定

grid（複雑なレイアウト向け）

.container {
    display: grid;
    grid-template-columns: 1fr 1fr 1fr;
    gap: 20px;
}
