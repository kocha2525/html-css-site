CSS 基本プロパティまとめ

文字に関するプロパティ

プロパティ 説明
color 文字色
font-size 文字サイズ
font-weight 太さ
font-family フォント
text-align 配置
line-height 行間
text-decoration 下線など

color

文字色を変えるプロパティ

    p {
        color: #fff;  ←文字色
    }

色の指定方法

方法 例 説明
カラーコード #ff0088 もっとも一般的
RGB rgb(255,0,136) 0～255で指定
RGBA rgba(255,0,136,0.5) 透明度付き
色名 red/blue/green etc... 147色のみ

※自分が思うような色にしたいときはカラーピッカーなどのサイトを利用し、
なるべくカラーコードを使うようにしたほうが良い

font-weight

文字の太さを変えるプロパティ

    p {
        font-weight: bold; ← 太字 
        font-weight: 400; ← 標準 
        font-weight: 800; ← かなり太い 
    }

font-family

フォントを指定するプロパティ

    p {
        font-family: "";  ←好きなフォントの正式名所入力
    }

text-align

文字の位置を指定するプロパティ

    p {
        text-align: left;  ←左揃え
        text-align: center;  ←中央揃え
        text-align: right;  ←右揃え
        text-align: justify;  ←両端揃え
    }

line-height

文字の上下の余白を調整するプロパティ

    p{
        line-height: 1.5;  ←単位なし推奨
        line-height: 150%;  ←パーセント
        line-height: 36px;  ←ピクセル指定
    }

text-decoration

文字に装飾をつけるためのプロパティ

    p {
        text-decoration: underline;  ←下線
        text-decoration: overline;  ←上線
        text-decoration: line-through;  ←取り消し線
        text-decoration: none;  ←線を消す(主にリンクの下線を消したいときとかに使う)
    }

※線の種類や色、太さ、文字との距離などをまとめて書くことができるが
ここでは割愛

HTML/CSSにおける単位の説明

結論から言うと単位は大きく分けて3つある！

  • 絶対単位（固定サイズ）
  • 相対単位（親や画面に合わせて変わる）
  • 特殊単位（CSS独自の便利に使えるもの）

①絶対単位

画面が変わっても大きさが変わらない単位

単位 読み方 意味
px ピクセル 一番よく使う！ディスプレイにある点の数
cm センチ 印刷用
mm ミリ 印刷用
in インチ 印刷用(1in = 2.54cm)
pt ポイント 印刷用(1pt = 1/ 72in)

この中だとウェブではほとんどpxを使うでぇ

他は印刷向けだから、webではほとんど使わん

②相対単位（状況に応じてサイズが変わる）

レスポンシブデザインで最重要！

※レスポンシブデザイン = 画面サイズが異なる端末に合わせて表示レイアウトを
　　　　　　　　　　　　　　自動的に最適化する政策手法のこと

・%(パーセント)

親要素に対する割合

    width: 50%;  ←親の半分

・em(親のフォントサイズ基準)

1em = 親のfont-size

    font-size: 20px;
    padding: 1em;  ←20px

emは親のサイズに依存する！

・rem(ルートのフォントサイズ基準)

1rem = htmlのfont-size

    html{ font-size: 16px; }
    p{ font-size: 2rem; }  ←32px

※remはどこでも同じ基準！

・vw/vh(画面サイズ基準)

単位 意味
1vw 画面の横幅の1％
1vh 画面の高さの1％ 
    width: 100vw;  ←画面いっぱい
    height: 100vh;  ←全画面

※スマホ対応などでめちゃくちゃ使う

・vmin/vmax

単位 意味
vmin 画面の短い方の1％
vmax 画面の長い方の1％

→正方形を作るときに便利

    .square{
        width: 50vmin;
        height: 50vmin;
    }

　正直使うことほとんどない

③特殊単位（css独自の便利系）

ほかの単位だとできない or 複雑になってしまうことを

一発で解決できるようにしたのが特殊単位

・fr（Grid専用の割合単位）

    grid-template-colums: 1fr 2fr;

→左が１、右が２の比率で分割

・ch(文字幅基準)

「0 (ゼロ)」一文字分の幅

    width: 40ch;  ←40文字分の幅

→入力フォームとかでよく使う

・ex（x-height基準）

フォントのx軸の高さ

もうほぼ使わんし覚えんくても可

CSS単位最重要まとめ表

目的 使う単位
固定サイズにしたい px
文字サイズを安定させたい rem
文字に合わせて余白を調整したい em
横幅を割合で調整したい %
画面いっぱいにしたい vw/vh
正方形を作りたい vmin
Gridの比率を決めたい fr
入力欄の幅を文字数で決めたい ch

※ほかにもたくさん単位はあるがいったんはこれを覚えればある程度のことはできる

　慣れてきたらほかに便利な単位はたくさんあるので各自調べて学習していこう！

文字の設定（font-size/font-weight/font-family）

font-size(文字サイズ)

    p {
        font-size: 24px;
        font-size: 1.5em;
        font-size: 1.5rem;
    }

※サイズの単位設定で大きくレイアウトが変わってしまうので
　単位を適切に使う必要あり

余白に関するプロパティ

プロパティ 説明
margin 外側の余白
padding 内側の余白
margin-top 上の余白
padding-top 上の内側余白

margin/padding(余白)

margin(外側の余白)

    .box {
        margin: 20px;  ←全方向
        margin: 10px 20px;  ←上下　左右
        margin: 10px 20px 30px;  ←上　左右　下
        margin: 10px 20px 30px 40px;  ←上　右　下　左
    }

※サイズを増やしていくごとに細かく余白を設定できる！

padding(内側の余白)

    .box {
        padding: 10px;
    }
詳しくはボックスモデルのセクションで説明
