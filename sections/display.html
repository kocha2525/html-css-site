display の基礎

display とは？

display は、要素が「どのように表示されるか」を決めるプロパティ。
レイアウトを理解する上で最重要の概念。

代表的な display の種類

値 説明
block 縦に積まれる・幅は親いっぱい
inline 横に並ぶ・width/height不可
inline-block 横並び＋幅高さ指定可能
flex 柔軟なレイアウト
none 非表示(要素を完全に消す)

block（ブロック要素）

ブロック要素は「縦に積み重なるタイプ」

前後に自動で開業が入り、幅や高さを自由に指定できる

特徴 説明
改行される 次の要素は下に来る
width/height指定できる サイズを自由に変えられる
margin/padding全方向いける 余白も自由

代表的なブロック要素

  • div
  • p
  • h1～h6
  • ul/li
  • table

inline（インライン要素）

インライン要素は「横に並ぶ」タイプ

文字のように扱われ、幅や高さを指定できない！

特徴 説明
横に並ぶ テキストと同じ扱い
width/heightだめ サイズ指定できない
上下のmarginだめ 左右だけ有効

代表的なインライン要素

  • span
  • a
  • img
  • strong

inline-block(インライン＋ブロックのいいとこどり)

横に並ぶけど、width/heightも指定できる最強の中間タイプ

ボタンやメニューでよく使う。

特徴 説明
横に並ぶ インラインと同じ
width/heightいける ブロックと同じ
margin/padding全方向いける 余白も自由 
.button {
    display: inline-block;
    padding: 10px 20px;
    background: #0078ff;
    color: white;
}

ただしこのinline-brockは欠点が多すぎる…

  • 要素の間に謎の隙間ができる
  • 高さがそろわない
  • 横幅の計算が文字扱いでややこしい
  • レスポンシブが弱い
  • 中央揃えがややこしい
  • 高さ揃え・幅揃えがFlexより圧倒的に弱い

せやからinline-blockは便利やけど気を付ける点が多すぎるから
基本的にはFlex使っておくほうが無難ではある！

つまずきポイント

  • width が効かない → inline 要素に指定している
  • 横並びにならない → block のままになっている
  • ボタンの高さが揃わない → inline-block を使うべき
  • 要素を消したいのにスペースが残る → visibility:hidden と混同している

まとめ（これだけ覚えればOK）

  • レイアウトの基本は block と inline の違い
  • ボタンやメニューは inline-block が最強
  • 要素を消すなら display:none
  • サイズが効かないときは display を疑う
