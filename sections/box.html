ボックスモデル

ボックスモデルとは？

HTML のすべての要素は「四角い箱（ボックス）」として扱われる。 この箱は content → padding → border → margin の4層で構成されている。

content（中身）

テキストや画像など、実際の内容が入る部分。

padding（内側の余白）

content と border の間の余白。

文字が枠にくっつかないようにする

padding: 20px;

border（枠線）

要素の周りの線。

border: 2px solid black;

margin（外側の余白）

要素と要素の間の距離。

要素と要素の間隔をあけてあげるために使ったりする

margin: 30px;

margin と padding の違い

項目 意味
padding 要素の内側の余白（背景色が付く）
margin 要素の外側の余白（背景色は付かない）

width と height の注意点

CSS の width / height は content の大きさだけ を指定する。 padding や border は含まれない。

box-sizing（重要）

width に padding や border を含めたい場合は box-sizing: border-box; を使う。

* {
    box-sizing: border-box;
}

例：border-box の違い

/* 通常（content-box） */
.box1 {
    width: 200px;
    padding: 20px;
    background-color: yellowgreen;
}

/* border-box */
.box2 {
    width: 200px;
    padding: 20px;
    box-sizing: border-box;
    background-color: yellowgreen; 
}

実行イメージ

画像のようにデフォルトでサイズ指定したときpaddingも含まれるので
見た目の幅は 200px + (左右で20px+20pxなので)40px の240pxになる

しかしborder-boxを使うことでpaddingが中に押し込まれるので
見た目の幅はwidthだけに依存するため200pxになる

このようにpaddingを含めるか含めないかでもサイズが変わるので注意が必要

よくあるミス

  • width に padding が含まれていると思ってしまう
  • margin の相殺（margin collapse）を理解していない
  • 上下 margin が重なって思ったより広くなる
  • border-box を使わずにレイアウトが崩れる

margin の相殺（margin collapse）

上下の margin は重なって「大きい方だけ」適用される。

p {
    margin: 20px 0;
}
