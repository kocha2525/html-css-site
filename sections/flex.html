Flexbox（フレックスボックス）

Flexboxとは？

Flexbox は、要素を 横並び・縦並び・中央寄せ・均等配置 など
自由にレイアウトできる最強の仕組み。

基本構造

flex関連のプロパティを使うなら絶対に
display: flex;を親要素内に記述すること！

親：並べ方を決める

子：そのルールに従って動く

.container {
    display: flex;
}
.item {
    width: 100px;
    height: 100px;
    background: skyblue;
}

display: flex;のみで動かすとデフォルトのrowが動くので横並びになる！

横並び・縦並び

プロパティ 説明
flex-direction: row;(デフォルト) 横並び
flex-direction: column; 縦並び 
    .container {
        display: flex;  ←これ絶対いるよ
        flex-direction: row;  ←横並び
        flex-direction: column;  ←縦並び
    }

※補足※row、columnにrow-reverce、column-reverceのように
reverceを付け足すと右から左が左から右に変わるよ

flex-direction: column;の場合

※横並び、縦並びのプロパティーコードは基本的に
親要素の中にぶち込む

justify-content（横方向）

値 説明
flex-start 左寄せ
center 中央
flex-end 右寄せ
space-between 両端＋均等 
    .container {
        display: flex;
        justify-content: flex-start;  ←変えたい位置によって変更
    }

align-items（縦方向）

値 説明
flex-start 上揃え
center 中央揃え
flex-end 下揃え 
    .container {
        display: flex;
        align-items: flex-start;  ←変えたい位置によって変更
    }

表の上から順に実行するとこんな感じになるよ

縦方向の位置調整はこやつが担当！

flex-wrap(デフォルト)

最も基本の形、この形で書いてもデフォルトのレイアウトになる

デフォルトのレイアウト = 横並び

    .conteiner {
        display: flex;
        flex-wrap: nowrap;  ←基本の形 (flex-wrap: 指示する内容;)
    }

flex-wrap（折り返し）

Flexはデフォルトだと一行に詰め込もうとする

ほなどうすんねん↓

そこで使われるのがflex-wrap

wrap → 幅が足りなければ次の行に折り返す

幅が十分にある場合は折り返す必要がないのでデフォルトのまま表示される

幅が足りない場合にこのコードでは折り返しがされて二行になった

.container {
    display: flex;
    flex-wrap: wrap;
}

gap（余白）

昔まではmarginを使って余白を作っていたが、

今はgapだけで要素間のスペースが作れる！

.container {
    display: flex;
    gap: 20px;
}

※要素間の余白を作ることはできるが要素内の間隔は作れないので注意

Flexbox一覧表

親要素に使うプロパティ(display:flexのとき)

プロパティ 役割 主な値 説明
display Flexを有効か flex 親につけると子がFlexのルールで並ぶ
flex-direction 並ぶ方向 row/column 横並び/縦並び
flex-wrap 折り返し nowrap/wrap 幅が足りない時折り返す
justify-content 並ぶ方向の揃え方 flex-start/center/flex-end/space-between/space-around/space-evenly 横並びなら横方向、縦並びなら縦方向の揃え
align-items 並ぶ方向と逆方向の揃え flex-start/center/flex-end/stretch rowなら縦方向、columnなら横方向
align-content 複数行の揃え flex-start/center/flex-end/space-between/space-around/strech wrapした時の行全体の揃え
gap 要素間の余白 数値(px,rem等) 要素同士の間隔を作る（内側には効かない）

子要素に使うプロパティ

プロパティ 役割 説明
flex-grow 余ったスペースをどれだけ広げるか 1にすると伸びる、0なら伸びない
flex-shrink スペースが足りないとき縮む割合 1なら縮む、0なら縮まない
flex-basis 基本の幅（高さ） widthの代わりに使うことが多い
flex grow shrink basisのまとめ 例：flex: 1;は均等に広がる
align-self 個別の縦揃え align-itemsを上書きできる

よく使う組み合わせ

目的 よく使う設定
横並びにしたい display: flex;
縦並びにしたい flex-direction: column;
横方向の中央寄せ justify-content: center;
縦方向の中央寄せ align-items: center;
完全中央寄せ（上下左右） justify-content: center; align-content: center;
均等配置 justify-content: space-between;
折り返しレイアウト flex-wrap: wrap;
要素間の余白 gap: 20px;
子要素を均等に広げる flex: 1;
