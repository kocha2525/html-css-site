HTML基礎

HTMLとは？（大まかに紹介）

HTML（HyperText Markup Language）は、Webページの「骨組み」を作るための言語。
見出し・段落・画像・リンクなど、ページの構造を決める役割を持つ。
プログラミング言語ではあるが正確にはマークアップ言語と呼ばれるものになる！

HTMLの基本構造

<!DOCTYPE html>
<html lang="ja">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>ページタイトル</title>
</head>

<body>
　　ここには主にページに表示される内容かくにょ
</body>
</html>

各タグの役割

タグ 役割
<!DOCTYPE html> HTMLのバージョン宣言
<html> HTML文書の開始
<head> ページ情報（タイトルなど）
<meta> 文字コードや説明文などの設定
<title> ブラウザのタブに表示されるタイトル
<body> 画面に表示される内容を書く場所

よく使うHTMLタグ

主にbodyの中に書くやつ

タグ 意味
<h1>〜<h6> 見出し
<p> 段落
<br> 改行
<a href=""> リンク
<img src="" alt=""> 画像
<ul><li> 箇条書き
<div> ブロック要素（大きなまとまり）
<span> インライン要素（小さな範囲）

属性とは？

タグに追加情報を与えるもの。コーディング例：

    <a href="https://example.com" target="_blank">リンク</a>
属性 意味
href リンク先のURL
src 画像ファイルのパス
alt 画像が表示されない時の説明文(アクセシビリティとしても非常に有効なので必ず書くよ！)
id ページ内で1つだけの識別名
class 複数の要素に付けられるグループ名
target="_blank" 新しいタブで開く

※idやclass要素はcssを使うときによく使うから使い方覚えておく！

HTMLで絶対守るべきルール！

  • h1は1ページに一つだけ
  • p要素の中に<div>や<h1>は使わない
  • 画像には必ず alt (画像の説明)を付ける！（アクセシビリティ）
  • タグは必ず正しく閉じる！

よくあるミス

  • レイアウトが崩れる→タグの閉じ忘れ確認！
  • 画像が表示されない→ファイルの場所を間違えてるかそもそも写真をアップロードできてないかも…
  • 箇条書き要素をli単体で使ったりする
    正しくは写真の通りに書く
    ul要素の中にli要素を使う感じ！
