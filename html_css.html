HTML基礎 CSS基礎 セレクタ ボックスモデル テーブル Flexbox float レイアウト応用

HTMLとは？（大まかに紹介）

HTML（HyperText Markup Language）は、Webページの「骨組み」を作るための言語。 見出し・段落・画像・リンクなど、ページの構造を決める役割を持つ。

HTMLの基本構造

<!DOCTYPE html> <html lang="ja"> <head> <meta charset="UTF-8"> <meta name="viewport" content="width=device-width, initial-scale=1.0"> <title>ページタイトル</title> </head> <body> ページに表示される内容 </body> </html>

各タグの役割

タグ 役割
<!DOCTYPE html> HTMLのバージョン宣言（今はこれ一択）
<html> HTML文書の開始
<head> ページの情報（タイトル・文字コードなど）
<meta> 文字コードや説明文などの設定
<title> ブラウザのタブに表示されるタイトル
<body> 画面に表示される内容を書く場所

よく使うHTMLタグ

タグ 意味
<h1>〜<h6> 見出し（数字が小さいほど重要）
<p> 段落（文章）
<br> 改行（段落の中で使う）
<a href=""> リンク
<img src="" alt=""> 画像
<ul><li> 箇条書き
<div> ブロック要素（大きなまとまり）
<span> インライン要素（小さな範囲）

属性とは？

タグに追加情報を与えるもの。例：

<a href="https://example.com" target="_blank">リンク</a>
属性 意味
href リンク先のURL
src 画像ファイルのパス
alt 画像が表示されない時の説明文
id ページ内で1つだけの識別名
class 複数の要素に付けられるグループ名
target="_blank" 新しいタブで開く

HTMLで絶対に守るべきルール

  • <h1>は1ページに1つだけ
  • <p>の中に<div>や<h1>は入れない（ブラウザが勝手に閉じる）
  • 画像には必ず alt を付ける（アクセシビリティ）
  • タグは必ず正しく閉じる

つまずきポイント

  • 画像が表示されない → パス（場所）が間違っている
  • 文字化けする → charset="UTF-8" がない or 保存形式が違う
  • リンクが開かない → href のURLが間違っている
  • レイアウトが崩れる → <div>の閉じ忘れ

CSSとは？（大まかに紹介）

CSS（Cascading Style Sheets）は、HTMLで作った「骨組み」に対して、 色・大きさ・余白・配置などの「見た目」を指定するための言語。 HTMLが“構造”、CSSが“デザイン”を担当する。

CSSの基本書式

セレクタ { プロパティ: 値; }

例：h1 の文字サイズを24pxにする

h1 { font-size: 24px; }

基本書式を詳しく説明すんで！

セレクタってなんぞや？

「どの部分にCSSを適用するか」を指定するもの。

種類 例 意味
要素セレクタ p pタグすべてに適用
IDセレクタ #main id="main" の要素に適用
クラスセレクタ .title class="title" の要素に適用
子孫セレクタ #main p #main の中の p に適用
擬似クラス a:hover マウスが乗った時に適用

プロパティとは？

「何を変更するか」を指定する項目。

プロパティ 意味
color 文字色
background-color 背景色
font-size 文字サイズ
margin 外側の余白
padding 内側の余白
border 枠線

値とは？

プロパティを「どう変えるか」を指定する具体的な数値や色。

font-size: 24px; color: #ff0000; width: 80%;

CSSの書き方（3つの方法）

① インラインCSS（HTMLタグの中に書く）

<h1 style="color: red;">タイトル</h1>

→ テスト用。大量に使うのは非推奨。
　せやからまぁどんな感じに変わるか試すときとかにつかうんがええかも。

② head内に書く（埋め込みCSS）

<style> p { color: blue; } </style>

③ 外部CSS（最も推奨）

<link rel="stylesheet" href="style.css">

→ 複数ページで同じCSSを使えちゃうのよ。せやから更新がむっちゃ楽。

CSSの優先順位（重要）

同じ場所に複数のCSSがあると、どれが適用されるか決まっている。

優先順位 説明
① インラインCSS 最強。タグに直接書く。
② head内のstyle ページ内で書いたCSS
③ 外部CSS style.css など
④ ブラウザのデフォルト 一番弱い

詳細度（セレクタの強さ）

セレクタにも“強さ”がある。

セレクタ 強さ
#id 1.0.0（強い）
.class 0.1.0
タグ名 0.0.1（弱い）

例：同じ要素に複数のCSSがある場合

#title { color: red; } /* 強い */ .title { color: blue; } /* 中 */ h1 { color: green; } /* 弱い */

→ この場合、赤が適用される。

つまずきポイント

  • CSSが反映されない → CSSファイルのパスが間違っている
  • 色が変わらない → 詳細度（セレクタの強さ）で負けている
  • 外部CSSが効かない → <link> の書き方ミス
  • フォントサイズが変わらない → 単位(px/em/rem)の理解不足

CSSセレクタ

セレクタとは「どの要素にCSSを適用するか」を指定するためのもの。 これを理解すると、ページ全体を自由にデザインできるようになる。

1. 要素セレクタ（もっとも基本）

タグ名をそのまま指定してスタイルを当てる。

p { color: blue; }

→ ページ内の <p> 全部が青になる。

2. クラスセレクタ（最もよく使う）

複数の要素に同じデザインを当てたいときに使う。

<p class="lead">文章</p> .lead { font-size: 20px; color: #333; }

→ class は何回でも使える。デザインの“グループ名”。

3. IDセレクタ（1ページに1つだけ）

特定の1つの要素だけにスタイルを当てたいとき。

<h1 id="title">見出し</h1> #title { color: red; }

→ id は1ページに1回だけ。強さも強い。

4. 子孫セレクタ（範囲を絞る）

「Aの中にあるBだけ」にスタイルを当てる。

#main p { color: green; }

→ #main の中の p だけが緑になる。

5. 直接の子セレクタ（＞）

「すぐ下の階層の子だけ」を指定する。

#main > p { font-weight: bold; }

→ #main の直下の p だけ太字になる。

6. 擬似クラス（状態によって変わる）

リンクやボタンの“状態”に応じてスタイルを変える。

擬似クラス 意味
a:hover マウスが乗ったとき
a:active クリック中
a:visited 訪問済みリンク
input:focus 入力欄が選択されたとき
a:hover { color: #0090ff; }

7. nth-child（順番で指定）

「n番目の要素」にスタイルを当てる。

()内の数字は何番目かの指定だにょ

li:nth-child(3) { color: red; }

→ 3番目の li だけ赤になる。

※三番目がもしliではなかったら適応されない！

8. nth-of-type（同じタグの中でn番目）

タグの種類ごとに数える。

p:nth-of-type(2) { font-size: 20px; }

→ 2番目の p だけ大きくなる。

※pのタグしか見ないから間にliとかあっても飛ばして三番目のpに適応される

9. セレクタの強さ（詳細度）

複数のCSSがぶつかったとき、どれが勝つかを決めるルール。

セレクタ 強さ
#id 1.0.0（最強）
.class 0.1.0
タグ名 0.0.1（弱い）
#title { color: red; } /* 勝つ */ .title { color: blue; } h1 { color: green; }

10. よくある間違い

  • class と id の使い分けが逆になっている
  • 子孫セレクタのスペースを忘れる（#mainp ではなく #main p）
  • hover が効かない → a:link や a:visited の順番が逆
  • nth-child と nth-of-type の違いが分からない

CSS 基本プロパティ

CSSのプロパティは「見た目をどう変えるか」を指定するための項目。 ここでは、Web制作で絶対に使う基本プロパティだけをまとめる。

1. 色指定（color / background-color）

文字色と背景色を変えるプロパティ。

p { color: #ff0000; /* 文字色 */ background-color: #f5f5f5; /* 背景色 */ }

色の指定方法

方法 例 説明
カラーコード #ff0088 最も一般的
RGB rgb(255, 0, 136) 0〜255で指定
RGBA rgba(255,0,136,0.5) 透明度つき
色名 red / blue / green 147色のみ

2. 文字の設定（font-size / font-weight / font-family）

font-size（文字サイズ）

p { font-size: 24px; font-size: 1.5em; font-size: 1.5rem; }
単位 意味
px 絶対値。初心者はまずこれ。
em 親要素の文字サイズ基準
rem htmlの文字サイズ基準
% 相対サイズ

font-weight（文字の太さ）

p { font-weight: bold; /* 太字 */ font-weight: 400; /* 標準 */ font-weight: 800; /* かなり太い */ }

font-family（フォント）

p { font-family: "Hiragino Kaku Gothic Pro", "MS PGothic", sans-serif; }

3. text-align（文字の位置）

p { text-align: left; /* 左揃え */ text-align: center; /* 中央揃え */ text-align: right; /* 右揃え */ text-align: justify; /* 両端揃え */ }

4. line-height（行間）

文字の上下の余白を調整する。

p { line-height: 1.5; /* 単位なし推奨 */ line-height: 150%; /* パーセント */ line-height: 36px; /* px指定 */ }

5. 背景（background / background-image）

背景色

.box { background-color: #000; }

背景画像

.box { background-image: url("img/bg.png"); background-repeat: no-repeat; background-size: cover; }

6. margin / padding（余白）

margin（外側の余白）

.box { margin: 20px; /* 全方向 */ margin: 10px 20px; /* 上下 左右 */ margin: 10px 20px 30px; /* 上 左右 下 */ margin: 10px 20px 30px 40px; /* 上 右 下 左 */ }

padding（内側の余白）

.box { padding: 10px; }

margin と padding の違い

プロパティ 意味
margin 要素の外側の余白（背景色なし）
padding 要素の内側の余白（背景色あり）

7. border（枠線）

.box { border: 1px solid #333; }

主なスタイル

値 意味
solid 実線
dotted 点線
dashed 破線
double 二重線

8. width / height（サイズ）

.box { width: 300px; height: 200px; }

※インライン要素（spanなど）には基本的に効かない。

つまずきポイント

  • padding と margin の違いが分からない
  • 背景画像が表示されない → パスが間違っている
  • line-height の単位を混乱する
  • width が効かない → インライン要素に指定している

ボックスモデルとは？

HTMLのすべての要素は「四角い箱（ボックス）」として扱われる。 この箱は content → padding → border → margin の4層でできている。 レイアウトを理解するうえで最重要の概念。

ボックスモデルの構造

┌───────────────────────────┐ │ margin（外側の余白 │ │ ┌───────────────────────┐ │ │ │ border（枠線） │ │ │ │ ┌───────────────────┐ │ │ │ │ padding（内側の余白） │ │ │ │ │ ┌───────────────┐ │ │ │ │ │ content（中身） │ │ │ │ │ └───────────────┘ │ │ │ └───────────────────┘ │ │ └───────────────────────┘ │ └───────────────────────────┘

1. content（中身）

テキストや画像など、実際に表示される内容。

2. padding（内側の余白）

content と border の間の余白。背景色がつく。

.box { padding: 20px; }

3. border（枠線）

要素の周りの線。太さ・色・スタイルを指定できる。

.box { border: 2px solid #333; }
スタイル 意味
solid 実線
dotted 点線
dashed 破線
double 二重線

4. margin（外側の余白）

要素の外側の余白。背景色はつかない。

.box { margin: 20px; }

margin と padding の違い

プロパティ 意味
padding 内側の余白（背景色あり）
margin 外側の余白（背景色なし）

5. margin の相殺（つまずきやすいとこ）

上下の margin は「大きい方だけが適用される」現象が起きる。 これを margin collapse（マージンの相殺）という。

p { margin: 20px 0; }

上下に並んだ要素の margin が 20px と 10px なら、結果は 20px になる。

6. box-sizing（サイズ計算を変える）

width の計算方法を変えるプロパティ。 デフォルトでは padding と border が width に足されるため、意図しないサイズになることがある。

デフォルト（content-box）

width は content の幅だけを指す。

.box { width: 200px; /* content の幅 */ padding: 20px; /* 実際の幅は 240px になる */ }

おすすめ：border-box

padding と border を含めて width として扱う。

.box { box-sizing: border-box; }

→ 実務ではほぼ全員これを使う。

7. よくあるミス

  • padding と margin の違いが分からない
  • width が思ったより大きくなる → box-sizing を使っていない
  • 上下の margin が消える → margin の相殺
  • 背景色が padding にしかつかない理由が分からない

display（要素の表示形式）

display は「要素がどう並ぶか」「サイズが指定できるか」を決める最重要プロパティ。 HTMLタグにはそれぞれ“初期の表示形式”がある。

1. block（ブロック要素）

ブロック要素は「縦に積み重なる」タイプ。 前後に自動で改行が入り、幅や高さを自由に指定できる。

特徴 説明
改行される 次の要素は下に来る
width/height 指定OK サイズを自由に変えられる
margin/padding 全方向OK 余白も自由

代表的なブロック要素

  • <div>
  • <p>
  • <h1>〜<h6>
  • <ul> / <li>
  • <table>
.box { display: block; width: 300px; height: 100px; }

2. inline（インライン要素）

インライン要素は「横に並ぶ」タイプ。 文字のように扱われ、幅や高さを指定できない。

特徴 説明
横に並ぶ テキストと同じ扱い
width/height NG サイズ指定できない
上下のmargin NG 左右だけ有効

代表的なインライン要素

  • <span>
  • <a>
  • <img>（例外でサイズ指定OK）
  • <strong>
.text { display: inline; }

3. inline-block（インライン＋ブロックのいいとこ取り）

横に並ぶけど、width/height も指定できる“最強の中間タイプ”。 ボタンやメニューでよく使う。

特徴 説明
横に並ぶ インラインと同じ
width/height OK ブロックと同じ
margin/padding 全方向OK 余白も自由
.btn { display: inline-block; padding: 10px 20px; background: skyblue; border-radius: 5px; }

4. none（非表示）

要素を完全に消す。 画面にも表示されず、スペースも残らない。

.hidden { display: none; }

5. つまずきポイント

  • width が効かない → inline 要素に指定している
  • 横並びにならない → block のままになっている
  • ボタンの高さが揃わない → inline-block を使うべき
  • 要素を消したいのにスペースが残る → visibility:hidden と混同している

6. まとめ（これだけ覚えればOK）

  • レイアウトの基本は block と inline の違い
  • ボタンやメニューは inline-block が最強
  • 要素を消すなら display:none
  • サイズが効かないときは display を疑う

テーブル（表）の作り方

テーブルは「表形式のデータ」を表示するためのHTML要素。 <table> → <tr> → <th> / <td> の順で作る。

1. 基本構造

<table> <tr> <th>見出し</th> <th>見出し</th> </tr> <tr> <td>データ</td> <td>データ</td> </tr> </table>

2. 各タグの意味

タグ 意味
<table> 表全体
<tr> 行（row）
<th> 見出しセル（太字・中央揃え）
<td> データセル

3. CSSで表を整える（必須）

HTMLだけだと表はダサい。CSSで見やすくする。

table { border-collapse: collapse; /* 線を重ねてスッキリ */ width: 100%; } th, td { border: 1px solid #333; padding: 10px; text-align: center; }

4. セルの結合（rowspan / colspan）

横方向に結合（colspan）

<td colspan="2">2列分を結合</td>

縦方向に結合（rowspan）

<td rowspan="2">2行分を結合</td>

5. thead / tbody（意味的に正しい表）

大規模な表では意味的に分けると読みやすくなる。

<table> <thead> <tr><th>名前</th><th>年齢</th></tr> </thead> <tbody> <tr><td>山田</td><td>23</td></tr> <tr><td>佐藤</td><td>25</td></tr> </tbody> </table>

6. border-collapse の違い

値 意味
collapse 線を重ねて1本にする（一般的）
separate セルの線を分離（古いデザイン）

7. border-spacing（separate時のみ有効）

table { border-collapse: separate; border-spacing: 20px; }

8. よくあるミス

  • セルがくっつく → border-collapse を忘れている
  • 線が二重になる → collapse を使っていない
  • セル結合でズレる → colspan / rowspan の数が合っていない
  • テーブルが読みにくい → padding が足りない

9. 実務でよく使うテーブルテンプレ

<table class="basic-table"> <tr> <th>項目</th> <th>内容</th> </tr> <tr> <td>名前</td> <td>山田太郎</td> </tr> </table> .basic-table { border-collapse: collapse; width: 100%; } .basic-table th, .basic-table td { border: 1px solid #333; padding: 10px; }

Flexbox（フレックスボックス）

Flexbox は「横並び・縦並び・中央寄せ・均等配置」を 短いコードで実現できる最強のレイアウト技術。 これを理解すれば、float や table に頼らず自由にレイアウトできる。

1. Flexboxの基本構造

Flexboxは「親 → 子」の関係で動く。

親（コンテナ） { display: flex; } 子（アイテム） { /* 並び方は親が決める */ }

図解イメージ

┌─────────────── 親（display:flex） ───────────────┐ │ [子1] [子2] [子3] [子4] [子5] ← これらが「Flexアイテム」 │ └────────────────────────────────────┘

2. flex-direction（並び方向）

子要素を横に並べるか、縦に並べるかを決める。

.container { display: flex; flex-direction: row; /* 横並び（デフォルト） */ /* flex-direction: row-reverse; 右→左 */ /* flex-direction: column; 縦並び */ /* flex-direction: column-reverse; 下→上 */ }

図解

値 並び方
row 左 → 右（横並び）
row-reverse 右 → 左
column 上 → 下（縦並び）
column-reverse 下 → 上

3. justify-content（横方向の位置）

主軸（flex-direction の方向）に対して、子要素をどう並べるか。

.container { display: flex; justify-content: center; }
値 意味
flex-start 左寄せ（デフォルト）
center 中央寄せ
flex-end 右寄せ
space-between 両端揃え（間隔均等）
space-around 周囲に均等な余白

4. align-items（縦方向の位置）

交差軸（主軸と直角方向）に対しての揃え方。

.container { display: flex; align-items: center; }
値 意味
flex-start 上揃え
center 中央揃え
flex-end 下揃え
stretch 高さを自動で伸ばす（デフォルト）

5. flex-wrap（折り返し）

横幅が足りないときに折り返すかどうか。

.container { display: flex; flex-wrap: wrap; /* 折り返す */ }
値 意味
nowrap 折り返さない（デフォルト）
wrap 下に折り返す
wrap-reverse 上に折り返す

6. 子要素側のプロパティ（flex-grow / flex-shrink / flex-basis）

flex-grow（余白をどれだけ広げるか）

.item { flex-grow: 1; /* 空いたスペースを均等に広げる */ }

flex-basis（基本の幅）

.item { flex-basis: 200px; /* 最初の幅 */ }

flex（まとめて指定）

.item { flex: 1; /* grow:1 shrink:1 basis:0 の省略形 */ }

7. 実践：横並びメニュー

  • MENU1
  • MENU2
  • MENU3
  • MENU4
#nav { list-style: none; display: flex; justify-content: center; } #nav li { margin: 0 10px; } #nav a { padding: 10px 20px; background: #333; color: #fff; text-decoration: none; }

8. よくあるミス

  • justify-content と align-items の役割を逆に覚える
  • flex-direction を変えたのに揃え方が変わらない → 主軸が変わっている
  • 高さが揃わない → align-items を center にしていない
  • 折り返しが効かない → flex-wrap を忘れている

9. まとめ（Flexboxはこう覚える）

  • display:flex を書いた瞬間、子要素は“Flexアイテム”になる
  • 横並び → justify-content
  • 縦揃え → align-items
  • 折り返し → flex-wrap
  • 子要素の幅調整 → flex / flex-basis

float（回り込み）

float は本来「画像の回り込み」を作るためのプロパティ。 しかし昔はレイアウトにも使われていたため、今でも理解が必要。 Flexbox が登場した今は、float は“補助的な技術”として覚えておけばOK。

1. float の基本

要素を左 or 右に寄せて、後続の要素を回り込ませる。

.box { float: left; /* 左に寄せる */ /* float: right; 右に寄せる */ /* float: none; 初期値 */ }

2. float を使った横並び

昔の横並びレイアウトは float で作っていた。

.box1 { float: left; width: 200px; } .box2 { float: left; width: 200px; }

→ 2つのボックスが横に並ぶ。

3. 回り込みを解除する（clear）

float を使うと、後続の要素が回り込んでしまう。 それを防ぐのが clear。

.footer { clear: both; /* 左右どちらのfloatも解除 */ }
値 意味
left 左のfloatを解除
right 右のfloatを解除
both 左右どちらも解除（基本これ）

4. 親要素が消える問題（floatの最大の罠）

子要素に float を使うと、親要素が高さを認識できず“潰れる”。 これが float 最大のトラブル。

例：親が消える

.parent { background: #eee; } .child { float: left; width: 200px; height: 100px; }

→ 親の背景が消える（高さ0になる）。

5. 解決方法① overflow:hidden を使う

最も簡単でよく使われる方法。

.parent { overflow: hidden; }

→ 親が float を含む高さを認識する。

6. 解決方法② clearfix（クリアフィックス）

昔から使われている“定番の解決法”。

.clearfix::after { content: ""; display: block; clear: both; }

HTML側

7. float の実用例（画像の回り込み）

本来の使い方はこれ。

img { float: left; margin: 0 20px 20px 0; }

→ 画像の右側に文章が回り込む。

8. float を使った2カラムレイアウト（昔の方法）

.left { float: left; width: 50%; } .right { float: right; width: 50%; } .footer { clear: both; }

9. よくあるミス

  • 親要素が消える → overflow:hidden or clearfix を忘れている
  • 要素が変な位置に回り込む → clear を使っていない
  • 横並びが崩れる → width の合計が100%超えている
  • float でレイアウトしようとする → Flexbox を使うべき

10. まとめ（floatはこう覚える）

  • float は「回り込み」のための技術
  • レイアウトは Flexbox を使う（float は補助）
  • 親要素が消える問題は overflow:hidden か clearfix
  • 回り込み解除は clear:both

応用レイアウト（ナビゲーション・Flexbox応用）

ここでは、実際のWebサイトでよく使われるレイアウトをまとめる。 float・inline-block・Flexbox の3種類を紹介するが、 現代の標準は Flexbox 一択。 float は歴史的理由で授業に出るだけ。

1. 基本の横並びナビゲーション（Flexbox版・最推奨）

HOME ABOUT SERVICE CONTACT
#nav { display: flex; justify-content: center; align-items: center; gap: 20px; /* ボタン間の余白 */ } #nav a { padding: 10px 20px; background: #333; color: #fff; text-decoration: none; border-radius: 4px; }

→ Flexbox ならたったこれだけで綺麗な横並びが完成。

2. 左寄せナビ（Flexbox）

#nav { display: flex; justify-content: flex-start; }

3. 右寄せナビ（Flexbox）

#nav { display: flex; justify-content: flex-end; }

4. ロゴ左・メニュー右（実務でよく使う）

LOGO
ABOUT SERVICE CONTACT
#header { display: flex; align-items: center; } .logo { margin-right: auto; /* ロゴを左に押し出す */ } .menu { display: flex; gap: 20px; }

→ margin-right: auto; がポイント。

5. ボタン型ナビ（幅均等・実務でよく使う）

HOME ABOUT SERVICE NEWS CONTACT
#btn-nav { display: flex; justify-content: space-between; } #btn-nav a { width: calc(100% / 5 - 10px); text-align: center; padding: 15px 0; background: #ccc; text-decoration: none; color: #000; }

→ calc() を使うと均等幅が簡単に作れる。

6. 折り返し可能なメニュー（スマホ対応）

#nav { display: flex; flex-wrap: wrap; gap: 10px; }

→ flex-wrap: wrap; でスマホでも崩れない。

7. inline-block を使った横並び（古いが授業で出る）

#nav li { display: inline-block; margin-right: 10px; }

→ 文字間の隙間ができるのが欠点。

8. float を使った横並び（歴史的理由で覚える）

#nav li { float: left; margin-right: 10px; } #nav { overflow: hidden; /* 親要素が消える問題の対策 */ }

→ float はもうレイアウトには使わない。

9. よくあるミス

  • justify-content と align-items の役割を逆に覚える
  • ロゴを左に寄せたいのに margin-right:auto を使っていない
  • inline-block の隙間問題を知らない
  • float で親要素が消える → overflow:hidden を忘れている

10. まとめ（実務ではこう使う）

  • ナビゲーションは Flexbox 一択
  • ロゴ左・メニュー右は margin-right:auto
  • 均等幅は calc(100% / 個数)
  • スマホ対応は flex-wrap: wrap
  • float は歴史的理由で覚えるだけ
