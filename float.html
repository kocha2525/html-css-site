float（フロート）

floatとは？

float は本来「画像の回り込み」のための仕組み。
昔はレイアウトにも使われていたが、今は Flexbox が主流。
あまり覚える必要もないかも

基本の使い方

img {
    float: right;
    width: 150px;
    margin: 10px;
}

float の値

値 説明
left 左に寄せて回り込み
right 右に寄せて回り込み
none 回り込みなし

clearfix（クリアフィックス）

.clearfix::after {
    content: "";
    display: block;
    clear: both;
}

float の代わりに使うべきもの

  • Flexbox
  • Grid

なんでfloatは使わん（嫌われてるか）

昔はfloatでレイアウトしてたが、
レイアウトするのに使うにしては問題が多すぎた

  • 親の高さが消える
  • 回り込み解除(clear)が必要
  • 思った通りにそろわない
  • レスポンシブが難しい
  • 本来は"画像の回り込み"用なのにレイアウトに使われてた

せやから基本レイアウトではflexやgridを使用するのが今流ですわ
