CSS基礎

CSSとは？（大まかに紹介）

CSS（Cascading Style Sheets）は、HTMLで作った「骨組み」に対して
色・大きさ・余白・配置などの「見た目」を指定するための言語。

CSSの基本書式

セレクタ {
    プロパティ: 値;
}

例 1：文字を赤くする

p {
    color: red;
}

例 2：h1の文字サイズを24pxにする

h1 {
    font-size: 24px;
}

基本書式の説明!

セレクタってなんぞや？

「どの部分にCSSを適用するか」を指定するもの。

種類 例 意味
要素セレクタ p pタグすべてに適用
IDセレクタ #main id="main" の要素に適用
クラスセレクタ .title class="title" の要素に適用
子孫セレクタ #main p #main の中の p に適用
擬似クラス a:hover マウスが乗った時に適用

プロパティとは？

「何を変更するか」を指定する項目。

プロパティ 意味
color 文字色
background-color 背景色
font-size 文字サイズ
margin 外側の余白
padding 内側の余白
border 枠線

値とは？

プロパティを「どう変えるか」を指定する具体的な数値や色。

    font-size: 24px;
    color: #ff0000;
    width: 80%;

CSSの書き方（3つの方法）

① インラインCSS（HTMLタグの中に書く）

    <h1 style="color: red;">タイトル</h1>

→ テスト用。大量に使うのは非推奨。
　せやからまぁどんな感じに変わるか試すときとかにつかうんがええかも。

② head内に書く（埋め込みCSS）

    <style>
    p {
    color: blue;
    }
    </style>

　こんな感じでヘッド内にstyleタグを作りその中にcssを書いてあげる

③ 外部CSS（最も推奨）

    <link rel="stylesheet" href="style.css">

　こんな感じでヘッド内にlinkタグで別で作ったcssファイルを追加してあげる

→ 複数ページで同じCSSを使えちゃうのよ。せやから更新がむっちゃ楽。

CSSの優先順位（重要）

同じ場所に複数のCSSがあると、どれが適用されるか決まっている。

優先順位 説明
① インラインCSS 最強。タグに直接書く。
② head内のstyle ページ内で書いたCSS
③ 外部CSS style.css など
④ ブラウザのデフォルト 一番弱い

詳細度（セレクタの強さ）

セレクタにも“強さ”がある。

セレクタ 強さ
#id 1.0.0（強い）
.class 0.1.0
タグ名 0.0.1（弱い）

例：同じ要素に複数のCSSがある場合

    #title { color: red; } /* 強い */
    .title { color: blue; } /* 中 */
    h1 { color: green; } /* 弱い */

→ このコードを一気に書いた場合、赤が適用される。

つまずきポイント

  • CSSが反映されない → CSSファイルのパスが間違っている
  • 色が変わらない → 詳細度（セレクタの強さ）で負けている
  • 外部CSSが効かない → <link> の書き方ミス
  • フォントサイズが変わらない → 単位(px/em/rem)の理解不足→（css基本プロパティまとめページに説明あり）
